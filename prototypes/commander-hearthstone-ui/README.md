# Commander Hearthstone UI Prototype

Original lightweight browser prototype imported from `commander_hearthstone_ui_prototype(1).zip`.

Open `index.html` directly in a browser. It demonstrates a four-player Commander table layout, hand/board interaction, card inspection, simple casting, mana, draw/untap/end-turn controls, graveyard/exile placeholders, and a Hearthstone/MTG Arena-inspired presentation.

This is a UI prototype, not a rules-accurate MTG engine. EDH Sim's Python engine should remain separate from presentation and progressively replace the prototype's hard-coded game behavior.

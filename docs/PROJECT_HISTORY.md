# Project history

EDH Sim is the current name for the Commander simulation project.

Earlier work explored:
- a Hearthstone / MTG Arena-inspired Commander interface
- replacing a pool-table-like battlefield with a more fantasy/MTG-feeling environment
- using Card Forge / Forge as a reference point for Commander rules and simulation
- a Python-first goldfish simulator for Commander decks against computer opponents

The previously uploaded prototype and Forge ZIP archives are not copied into this repository because their original bytes are not currently recoverable from the project file library. Forge is also a third-party project and should not be blindly vendored into this repo. Recovered original EDH Sim source can be integrated when available.
